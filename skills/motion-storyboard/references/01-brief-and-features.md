# 01 · Brief → message and features

Most weak motion videos are weak before any animation: they try to say five things, so nothing lands. This stage decides what the video says and what it shows.

## 1. Pin the brief

Fill `templates/brief.md`. Required fields; ask once for any that are missing, default the rest and say so:

| Field | Question | Default |
|---|---|---|
| Product | What is it, in one sentence a 12-year-old understands? | — (must ask) |
| Audience | Who watches, where, and what do they already believe? | — (must ask) |
| Platform + aspect | Where does it play? | X/YouTube 16:9; Reels/TikTok 9:16; feed 1:1 |
| Length | Seconds | 15s social, 30s promo, 60s explainer |
| Takeaway | The one sentence the viewer must remember | derived in §2 |
| CTA | What should they do after? | URL or app name on the end card |
| Brand | Fonts, colours, logo, product screens | ask for files |
| Music | Track supplied? Licensed? | ask; placeholder only if they agree |
| Bans | Anything never to show or say | none |

## 2. Write the message as a claim

A topic names a subject; a claim says something that could be false.

| Topic (reject) | Claim (accept) |
|---|---|
| "About AvioMax" | "Sell to all of Nigeria in one link." |
| "Our new dashboard" | "Know what sold before your coffee cools." |
| "Privacy features" | "Your balance is nobody's business." |
| "Score prediction" | "Close still pays." |

Test: could a competitor say the same sentence? If yes, sharpen it with the product's own differentiator (6% commission, Paystack, verified sellers).

The tagline the client supplies ("Shop smart. Sell big.") is the *end card line*, not necessarily the message. The message is what the beats prove; the tagline is how the video signs off.

## 3. Pick 2–4 features, each with a proof moment

For each feature write the **proof moment**: the single on-screen event that makes the feature undeniable without a voiceover. A feature with no proof moment is a claim; claims belong in end cards, not beats.

| Feature | Weak depiction | Proof moment |
|---|---|---|
| Verified sellers | A "Verified" badge on a card | A seller card arrives unverified (grey), a check stamps on, the card lifts and turns accent |
| Low commission (6%) | "6% commission" text | A ₦10,000 sale splits on screen: ₦9,400 flies to the seller wallet, a thin ₦600 sliver peels off |
| Secure payments | Shield icon | The pay button is pressed, the card number collapses into a sealed token, "Paid" lands |
| Sell on social | Instagram/TikTok logos | One product link is pasted into three chat bubbles at once; three "New order" pings answer |

Rules:
- Number of features ≤ length in seconds ÷ 8. A 30s video shows 3 features at most; a 15s video, 1–2.
- Order features by what the audience doubts most, not by product importance.
- Each feature gets at least one beat of ~2.5–4s. If it cannot, cut a feature rather than speeding up.

## 4. Choose an arc

| Arc | Shape | Use when |
|---|---|---|
| Pain → turn → proof → sign-off | old way hurts, product appears, features prove it, logo + CTA | the audience feels a known pain |
| Promise → proof → proof → sign-off | claim first, then evidence | the benefit is obvious and exciting |
| Day in the life | one user's journey through the product | the product is a workflow |
| Before / after on one object | one object transforms piece by piece | a single dramatic improvement |
| Countdown / list | 3 reasons, 3 numbers | rapid social formats |
| Single metaphor | one terrain object carries the whole story | brand films, 15s stings |

Write the arc as a line: `Hook (pain) → Turn (logo) → Proof: buyers → Proof: sellers → Proof: trust → Sign-off`.

## 5. Output of this stage

```
Message: Sell to all of Nigeria in one link.
Takeaway on end card: "Shop smart. Sell big."
Audience: Nigerian small business owners selling on IG/TikTok/WhatsApp; shoppers burned by fake sellers.
Arc: Pain → Turn → Proof ×3 → Sign-off
Features (ordered by doubt):
  1. Verified sellers. Proof: a grey seller card gets stamped verified and lifts.
  2. 6% commission. Proof: a ₦10,000 sale splits; ₦9,400 lands in the wallet.
  3. Paystack secure. Proof: pay pressed, card number seals into a token, "Paid".
```
